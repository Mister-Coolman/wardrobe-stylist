# Wardrobe Stylist

Film your closet once. Each morning, get one outfit that fits your calendar, the weather and what's actually clean — and a packing list that never runs you out of shirts on a trip.

Built for Meta's Global AI Developer Hackathon (track: Build for Your World). **All code in this repository was written during the hackathon, 27 Oct – 4 Nov 2026.** The design docs in `docs/` were written on 26 Oct, before the build window.

## Run it

```bash
cp .env.example .env.local   # MODELS=mock works with no keys
npm install
npm run dev
```

More (models used, architecture) lands as the build progresses.
